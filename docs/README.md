## 🧭 按角色快速导航

### 我只是想弹琴
→ 看 **[操作手册.md](./操作手册.md)**，5 分钟上手。

### 我想在另一块板子上也烧一个
→ 看 **[烧录复刻指南.md](./烧录复刻指南.md)** 的**路线 A（直接烧现成固件）**，不用编译。

### 我想看懂它是怎么造出来的
→ 看 **[技术设计说明.md](./技术设计说明.md)**。核心就三件事：
1. 声音是芯片**现场算**出来的（不是播放音频文件）
2. **颜色就是音的身份证**（红=do、蓝=la）
3. 录的是**简谱**（按了哪个音、什么时候按的），不是录音

### 我要接手继续开发
→ 按顺序读：
1. `../flow/charter.md` —— 目标与边界（**先读这个**）
2. `../flow/decisions.md` —— 历史决策与踩过的坑
3. `技术设计说明.md` —— 实现方案与改动清单
4. `烧录复刻指南.md` —— 环境、编译与烧录

## ⚠️ 开发铁律

1. **先测后烧**——电脑上测试全绿，用户确认后才烧录
2. **烧录必验身**——核对完整 MAC 与芯片，不烧错板子
3. **硬件只信真相源**——引脚以 `easyinput-board-cy` 为准，不凭记忆写 GPIO
4. **不整片擦除 flash**
