# 八音琴 · 变更与会话记录

> 用途：跨轮次/跨上下文续接任务的**唯一进度台账**。每轮任务结束追加一条。
> 配套文件：`八音琴-需求与决策记录.md`（需求与规格冻结）、飞书作业文档（交付物）。
> 工程：`E:\easyIntput\easyinput-piano`（ESP-IDF / 纯 C，配套网页 `web/index.html`）

## 项目定位（重要）

- **这是一个新项目**：由学习者**自主构思**的「八音琴」，**课程（第 8 课）没有教**。
- 它**不是**老师布置课题的"功能扩展"；是学习者**基于这块开发板新开的项目**。
- 底子来自学习者**先前自己做的"电子琴/八音盒"固件**（那才是他之前的作品），八音琴是在其上重新设计交互与功能。
- 作业文档的叙述口径必须是「**新项目 / 自主构思**」。

## 硬件

ESP32-S3 板：8 键 S1~S8（低电平有效）、EC11 旋钮（A/B/按下）、5 颗 WS2812（D1~D5, GPIO12）、1 颗单色状态灯、喇叭、`rec` 分区（1MB，32KB/槽）。
