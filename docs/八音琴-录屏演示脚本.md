# 八音琴 · 录屏演示脚本

> 用途：课程作业演示录屏的**分镜脚本**。对照 `八音琴-需求与决策记录.md` / `八音琴-变更与会话记录.md`，按"文件夹模型"走一遍全部链路。
> 定位口径：**新项目**——学习者**自主构思**的「八音琴」，**课程没教**。
> 约定：**长按旋钮 ≥5 秒 = 回主目录**（任意场景通用）；**旋钮旋转 = 音量**（全场统一）。

---

## 一、分镜表

| 镜号 | 操作 | 预期现象（灯 / 语音 / 声音） | 口播词 | 时长 |
|---|---|---|---|---|
| **0** | 片头：黑底字幕或直接对着板子开讲（先不按任何键） | 静置；板子未上电或待机 | "这是我用课程开发板**自己构思**的一个新项目——八音琴。课上是没有教过的。" | 10s |
| **1** | **上电开机**（不按任何键） | 灯：自检后 **D1~D4 亮**（4 个入口）；语音："**请选择模式**"；声音：无 | "一开机它就在主目录，语音让我选模式，四颗灯就是四个入口。" | 8s |
| **2** | 按 **S1**（进"试听"） | 灯：**D1~D3 亮**（3 首内置曲）；语音：进入"试听"提示 | "按第一颗键进试听，这里有三首内置曲，三颗灯就是三首。" | 6s |
| **3** | 按 **S1** 选《小星星》 | 语音：报曲名"**小星星**" → **停约 3 秒** → 开始播放；播放时**只亮对应 D1**，**颜色随音符变**、其余灭 | "选小星星，它先报曲名，喘口气，再开始弹。" | 12s |
| **4** | **旋转旋钮** | 灯：不变；语音：无；声音：**音量变大/变小** | "转一下旋钮就是调音量，所有场景都通用。" | 8s |
| **5** | **短按旋钮**（暂停），稍停再**短按**一次（继续） | 语音："**暂停**" → "**继续**"；声音：停→续；灯：暂停时灭，继续时恢复随音符变色 | "短按是暂停，再短按就接着弹。" | 10s |
| **6** | 让它**自然播完** | 语音："**播放结束**"；灯：灭；声音：停 | "弹完它会说一句播放结束，很省心。" | 6s |
| **7** | **长按旋钮 ≥5 秒** 回主目录，再按 **S2**（进"自弹"） | 灯：回目录瞬间 **D1~D4 亮**；进入自弹后不亮音色灯；语音：进入"自弹"提示 | "长按旋钮五秒随时回主目录，再进第二个模式——自弹。" | 8s |
| **8** | 依次按 **S1~S8** 弹 8 个音（把**高音哆**也按一遍） | 声音：哆 唻 咪 发 嗦 啦 唏 **高音哆**；灯：每次**只亮对应 D_N、颜色随音符变** | "八个键就是八个音，最后一个是高音哆，灯会跟着音符变色。" | 20s |
| **9** | **短按旋钮**＝开始记谱，然后弹几个音 | 语音："**开始记录**"；灯：**只亮当前槽位那一颗**，随音符变色 | "短按一下开始记谱，现在弹的就都记下来了。" | 15s |
| **10** | **再短按旋钮**＝结束并保存 | 语音："**已保存**"（第 N 首）；灯：回空闲态 | "再短按一次就存好了。" | 6s |
| **11** | **长按旋钮 ≥5 秒** 回主目录，再按 **S4**（进"回放"） | 灯：空闲态**亮几颗 = 已存槽数**（本演示此时为 **D1~D2** 亮）；语音：进入"回放"提示 | "回主目录，进回放。亮几颗，就是里头存了几首。" | 8s |
| **12** | 按 **S1~S5** 选槽 | 灯：选中后**只亮对应 D_N**；语音：报槽位 | "按 S1 到 S5 挑槽，最多存五首。" | 8s |
| **13** | **短按旋钮**：播放 / 再短按暂停 | 声音：播放/停顿；灯：播放时只亮对应 D_N、随音符变色 | "短按旋钮就是播放和暂停。" | 10s |
| **14** | **长按旋钮 ≥5 秒** 回主目录，再按 **S3**（进"游戏"） | 灯：回目录 **D1~D4 亮**；进入后灯交由网页呈现；语音：进入"游戏"提示 | "最后一个模式是游戏，玩法在电脑网页上。" | 8s |
| **15** | 电脑网页打开「弓箭手」→ 点「开始游戏」，**键盘 1~8** 对准下落的音符按键（**8 = 高音哆**） | 网页：按对键→弓箭手射中、音符爆开加分；按错→箭射偏、音符砸落、本局结束；板子同步发声/亮灯 | "网页上小狐狸弓箭手会瞄准，按对键就射中；键 8 正好就是刚才的高音哆。" | 40s |
| **16** | 打**通关** | 网页：通关结算；本次 record 会话**自动落槽**保存 | "打通关以后，这首曲子会自动存进板子里。" | 10s |
| **17** | 回板上：**长按旋钮回主目录 → S4 回放 → 选槽 → 短按播放** 刚通关的曲子 | 灯：空闲亮数 **+1**（变成 D1~D3）；播放时只亮对应 D_N、随音符变色；声音：复现刚才弹的曲子 | "回板子上回放一下，刚才通关的曲子已经能原地重放了。" | 15s |
| **18** | 网页「🎵 曲库管理」：**新增 / 替换 / 删除** 一首，并**试听** | 网页：槽位信息更新（≤5 槽）；板子：同步听到试听音 | "网页这块是曲库管理，增、删、替换、试听都能做，最多五槽。" | 20s |
| **19** | 点「📥 一键放入 3 首内置儿歌」（**同步写 flash**），**断电重启**再看 | 网页：日志提示已写入槽 0/1/2；重启后槽位仍在 → **持久化成功** | "点一下就把三首儿歌写进 flash，断电重启也不会丢。" | 20s |
| **20** | 收尾：回到板子/网页成果画面 | 静置；画面切到测试与固件数据 | "电脑端自测全绿：宿主测试 **9/9**、网页 **41/41**，固件 **962,880 字节**，还留了约 **85.7 KB** 的 OTA 余量。作品链接就是我公开的飞书文档。" | 15s |

> 合计约 **4~5 分钟**。若时间紧，可砍 4、9、12 的时长，保留 3、10、16、17、19 的"关键证据"。

## 二、链路覆盖率自查

- [x] 开场：**新项目 / 自主构思 / 课程没教**
- [x] 开机 → **主目录**（语音"请选择模式" + **D1~D4 亮**）
- [x] **S1 试听**：进入语音 + D1~D3 亮 → 选曲报曲名 → 停 3 秒 → 播放（只亮 D_N、颜色随音符变）
- [x] 试听：旋钮**旋转调音量**；**短按暂停/继续**；播完"**播放结束**"

## 三、录制前检查清单

### 1. 烧录（关键：app 与语音分两处写）
- [ ] **app 烧到 `0x20000`（`ota_0`）**：`idf.py flash` 生成的就是这个地址；分区表里本工程的归属槽是 `ota_3`（1MB，即使放它也有 ≈85.7 KB 余量），但**本次实际落在 `ota_0`**。
- [ ] **语音必须单独写**：`tools/voice_prompts/voice_prompts.vpmt` 用 **esptool 写到 `rec` 分区 offset `0x9D8000`**。**漏了这一步就没有开机/提示语音**（会静默降级）。
- [ ] 遵循铁律：**插板 + 明确授权才烧**；**不整片擦除、不擦 NVS、不动分区表**。
- [ ] 烧完**关机 → 再开机**退出下载模式；确认开机听到"请选择模式"。

### 2. 本地服务器（网页部分要用）
- [ ] 在 `web/` 目录起：`python -m http.server 8765`。
- [ ] 浏览器开 **http://127.0.0.1:8765/**（**不要双击文件走 `file://`**，否则 Web Serial 连不上板子）。
- [ ] 页面点「**连接键盘**」，确认串口认到板子（先关掉其它占串口的监视器）。

### 3. 视听预设（录屏前调好，避免中途调）
- [ ] **音量**：先用旋钮把板子音量调到**清晰又不破音**的档位。
- [ ] **亮度**：网页/固件把灯亮度设为**不刺眼但上镜**（D1~D5 颜色要能拍清楚）。
- [ ] 环境：**安静、无回声**，测试录音回放时**口播不压琴声**（或先录画面、后配音）。

### 4. 口播稿速览（每镜 ≤2 句，口语化）
- 0 新项目自主构思 → 1 开机即主目录 → 2 试听三首 → 3 报曲名后播放 → 4 旋钮调音量 → 5 暂停/继续 → 6 播放结束 → 7 长按回目录进自弹 → 8 八音含高音哆 → 9 开始记谱 → 10 已保存 → 11 回放看槽数 → 12 选槽 → 13 播放/暂停 → 14 进游戏 → 15 网页弓箭手闯关 → 16 通关落槽 → 17 回板回放 → 18 曲库管理 → 19 一键儿歌写 flash → 20 成果交代。

### 5. 一图记住：终极按钮
> **长按旋钮 ≥5 秒 = 回主目录**；**短按旋钮**在本场景里另有含义（试听/回放＝暂停/继续；自弹＝开始/结束记谱）。别搞混。
