# 八音琴 · 真机（上板）逐项验收清单

> 用途：烧录到板子后，**逐项勾填**验收全部链路。每项填 `PASS` / `FAIL`，异常写进「实测备注」。
> 依据：`八音琴-需求与决策记录.md`（冻结规格）、`八音琴-变更与会话记录.md`（变更/已知限制）、`八音琴-录屏演示脚本.md`（链路走查），并对照固件 `firmware/main/main.c` 实际行为。
> 定位口径：**新项目·自主构思**（课程未教）。

## 0. 口径说明（先读，避免误判）

- **长按旋钮 ≥5 秒 = 回主目录**（任意场景通用）；**短按旋钮 = 本场景上下文动作**（试听/回放＝暂停/继续；自弹＝开始/结束记谱；主目录＝重播提示音）；**旋钮旋转 = 音量**（全场统一）。
- **键位范围**（以固件与《需求与决策记录》为准）：主目录 `S1~S4` 选模式、`S5~S8` 无功能；试听 / 回放 `S1~S5` 选曲 / 选槽、`S6~S8` 无功能；自弹 `S1~S8` ＝ 8 音。
- **灯铁律**：播放 / 弹奏态 **只亮当前那一颗 D_N**、颜色随音符变、其余灭；空闲 / 选曲态用「**亮几颗 = 数量**」。
- **音**：S1~S8 ＝ 哆 唻 咪 发 嗦 啦 唏 **高音哆**（8 音）。
- **已知限制**（会影响预期）：① 语音 `id9` 素材原话是「**已保存第五首**」（清单文案写作「已保存」）；② 「试听共五首 / 暂停 / 继续」3 句素材**未接线**，暂停 / 继续**无语音、只有声音停续**；③ 无 SPIRAM 时语音自动禁用；④ 歌名播报后首音**延后约 3 秒**（= 播报时长 + 150ms）。

## 一、烧录前置步骤（验收前必做）

- [ ] **插板 + 明确授权**：遵循铁律「不烧录，除非用户插板并明确授权」。
- [ ] **验身**：`python -m esptool --chip esp32s3 -p COM5 chip_id` → 确认芯片为 ESP32-S3 且 MAC 与预期同板。
- [ ] **app 烧到 `ota_3` 分区**（**不是**默认 app 分区；本工程预留 OTA，尾部余量约 85.7 KB）。
- [ ] **语音单独写**：用 **esptool 把 `tools/voice_prompts/voice_prompts.vpmt` 写到 `rec` 分区 offset `0x9D8000`**。
      → **漏了这一步就没有开机/提示语音，会静默降级**（画面上一切正常、只是全程无声）。
      → 离线校验：确认 `voice_prompts.vpmt` 存在（约 380,184 B，14 句 / 占 rec slot 5~16）。
- [ ] **禁止整片擦除**（不要 `--erase-all`）、**不擦 NVS**、**不动分区表**。
- [ ] **退出下载模式**：**关机 → 再开机**（下载模式只能靠断电退出）。
- [ ] **开机自检**：应听到「请选择模式」；若无声先别判 FAIL，先回查上面「语音单独写」这一步。
- [ ] **网页侧准备**（游戏 / 曲库管理要用）：`web/` 目录起 `python -m http.server 8765`，用 **http://127.0.0.1:8765/** 打开（**不要 file://**），点「连接键盘」并确认串口认到板子（先关掉占串口的监视器）。

## 二、验收顺序建议（从冒烟到边界）

1. **冒烟**（3 分钟定生死）：T01 开机主目录 → T04 进试听 → T05 播一首 → T13 进自弹 → T14 弹 8 音 → 听声音/看灯是否成立。
2. **主干链路**：A 主目录 → B 试听 → C 自弹 → D 回放 → E 游戏 → F 网页曲库。
3. **通用按钮**：J 长按回主目录（各场景各测一次）；K 无功能键位。
4. **语音专项**：G 的 V01~V14 逐句核对 + 让位。
5. **音色**：H。
6. **边界 / 防护**：I（串口误发、无 SPIRAM）——**留到最后**，避免污染已通过的主干结论。
