## 1. 心智模型：文件夹 / 子文件夹

- **开机即在主目录**（语音"请选择模式" + **D1~D4 亮** = 有 4 个入口）。
- **终极按钮：长按旋钮 ≥5 秒 = 回主目录**（任意场景通用）。
- **S1~S4** 进 4 个子目录：**试听 / 自弹 / 游戏 / 回放**。
- **旋钮旋转**：**主目录 = 灯亮度**（对 WS2812 D1~D5 与状态灯同时生效，掉电记忆）；**其它模式 = 音量**。（⚠️ **本条已由 R18 修订**，推翻此前"所有场景统一 = 音量"的口径。）

## 2. 键位与灯（最终）

| 场景 | S1~S8 | 旋钮旋转 | 旋钮短按 | 旋钮长按≥5s | 灯 |
|---|---|---|---|---|---|
| 主目录 | S1 试听 / S2 自弹 / S3 游戏 / S4 回放；S5~S8 报"本键无功能" | **亮度** | 重播提示音 | 已在主目录 | D1~D4 亮 |
| 试听 | S1~S5 选曲（S6~S8 无功能） | 音量 | 暂停 / 继续 | 回主目录（停播） | 空闲：亮数=曲目数；播放/选中：**只亮对应 D_N，颜色随音符变** |
| 自弹 | S1~S8 弹音 | 音量 | 开始记谱 / 再按=结束并保存 | 回主目录（记谱中→**自动保存**后退出） | 记谱中：**只亮对应槽位 D_N**，颜色随音符变；未记谱不亮音色灯 |
| 游戏 | 由网页判定 | 音量 | 无效→提示 | 回主目录 | 由网页呈现 |
| 回放 | S1~S5 选槽（S6~S8 无功能） | 音量 | 播放 / 暂停 | 回主目录（停播） | 空闲：亮数=已存槽数；播放：只亮对应 D_N 随音符变色 |

> **修订（R18 / 2026-10-15）**：上表中「主目录 · 旋钮旋转」由**音量**改为**灯亮度**；其余四态仍为**音量**。
> 亮度对所有模式生效（全局），掉电记忆（NVS `piano`/`brightness`，网页亮度滑块与旋钮同源）。
> 落盘策略：旋钮每格只置**脏标记**，**停转 ≥1.5s** 或**离开主目录**时**一次性写 NVS**（绝不每格写）。
> 步长 `ENC_BRIGHTNESS_STEP=16`，范围 `[8,255]`（集中定义于 `firmware/main/enc_dial.h`）。

**灯铁律**：① 任何"播放/弹奏"态 **只亮当前槽位那一颗 D_N**，颜色随音符变，其余灭；② 空闲/选曲态用"**亮几颗 = 数量**"（主目录 D1~D4、试听/回放 D1~Dn）；③ **不固定 D3**。

## 3. 曲库 / 回放池

- **5 槽**，`S1~S5` 选槽。
- 素材来源：**自弹记谱** + **游戏通关保存**。
- **回放池持久化到 `rec` 分区槽 21~25**（5 槽，每槽 32KB，带头部 magic/version/**seq**/count/校验/名字）：**上限 5 首，超出 FIFO 覆盖最旧的**（"最旧"按单调 **seq** 判断，不看槽序）；`push` 同时写 RAM 与 flash，开机从 flash 重建 5 槽。
- 网页曲库（试听池）仍走 `rec` 槽 0~4，可**新增/删除/替换**并**同步写 flash**（持久）——与回放池相互独立。
- 兜底：空槽播报"暂无记录"；游戏失败/中途退出 → 本次 record 会话**丢弃不落槽**。

> **修订（R21 / 2026-10-15，用户拍板）**：原"**自弹记谱只进 RAM（掉电即失）**"**作废**——回放池改为**持久化在 `rec` 槽 21~25**、上限 5 首、FIFO 覆盖最旧（按 seq 判序）。
> 相应地把 recorder 旧 flash 段收缩到 `rec` 槽 **26~31**（受保护段 0~25）。
