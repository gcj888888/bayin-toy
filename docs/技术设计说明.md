## 1. 核心思路：不是从零造，是拼装

EasyInput 社区已有成熟项目，我们把能用的零件全拿来用：

| 能力 | 从哪来 | 状态 |
|---|---|---|
| 发声链路（I2S 32kHz + 12 声道混音） | easyinput-beatbox `audio_click.c` | ✅ 现成，改造成 7 音高 |
| 读 8 个按键 | beatbox `board_keys.c`（`in.s[8]`） | ✅ 现成 |
| 五灯统一亮同色 | beatbox `led_status_set_solid_rgb()` | ✅ 现成 |
| 旋钮旋转计数 | beatbox 硬件 PCNT（4 倍频） | ✅ 现成 |
| **旋钮长按判定** | **easy-input-maker `encoder_press_gesture.cpp`** | ✅ 现成状态机，移植为 C |
| 网页双向通信 | beatbox `host_link`（JSON + USB-Serial-JTAG） | ✅ 现成（RX 已修） |
| 断电记忆 | beatbox NVS | ✅ 现成 |
| 硬件真相 / 防坑清单 | easyinput-board-cy | ✅ 现成 |

**要新写的只有两块**：音符合成（发声改造）+ 录制回放（业务逻辑）。

## 2. 发声：为什么选"现场合成"而不是"播放音频文件"

### 原理
声音 = 每秒 32000 个数字送给扬声器（采样率 32kHz），扬声器把它"抖"成声波。

**do 和 re 的区别，不是数字变多，而是这些数字连成的波浪每秒起伏几次**：
- do = 每秒起伏 262 次
- re = 294 次
- la = 440 次

### 三种做法对比

| 做法 | 怎么出声 | 音质 | 存储 | 采纳 |
|---|---|---|---|---|
| 播放采样文件 | 播提前录好的 .raw | 最好（能是真钢琴） | 占 Flash | ❌ |
| **现场合成** | 芯片实时算 `sin(2π·f·t)·衰减` | 中上（八音盒/木琴） | **零占用** | ✅ |
| 预生成数组 | 启动时算好存内存 | 中上 | 占内存 | ❌ |

### 为什么选现场合成

1. **ESP32-S3 带浮点运算器**，实时算 7 个音的正弦波毫不费力
2. **零存储占用**——不用准备 7 个音频文件
3. **音长灵活**——后面录音需要"按住多久响多久"，现场算天然支持
4. **换音色不用传文件**——音色就是几个参数（泛音比例、衰减速度），改数字即可

> 💡 这个方案是用户在讨论中提出的（"每秒32000个数字能造出 do re mi 吗？不就是项目3的原理吗"），比最初推荐的"播放采样"更优。

### 音色怎么调

```
采样值 = [ 基础正弦 + 泛音比例 × 高倍频正弦 ] × 衰减包络
```

| 音色 | 泛音比例 | 衰减 |
|---|---|---|
| 八音盒（清脆） | 少（0.2） | 快 |
| 钢琴感 | 中（0.35） | 中 |
| 长笛 | 极少（0.05） | 慢、平滑 |

参考实现：beatbox 的 `synthesize_clave()`（节拍器咔嗒声就是现场合成的，是现成范本）。

### 七个音的频率（C 大调）

| 音 | 频率 (Hz) | 音 | 频率 |
|---|---|---|---|
| do | 261.6 | sol | 392.0 |
| re | 293.7 | la | 440.0 |
| mi | 329.6 | si | 493.9 |
| fa | 349.2 | | |

升八度 = 频率 ×2，降八度 = ÷2。

## 3. 七音七色：颜色就是"音的身份证"

| 键 | 音 | 颜色 | RGB |
|---|---|---|---|
| S1 | do | 红 | 255, 40, 40 |
| S2 | re | 橙 | 255, 130, 0 |
| S3 | mi | 黄 | 255, 200, 0 |
| S4 | fa | 绿 | 0, 200, 60 |
| S5 | sol | 青 | 0, 200, 200 |
| S6 | la | 蓝 | 0, 80, 255 |
| S7 | si | 紫 | 170, 60, 255 |

**关键设计**：按下任意键，五颗灯**全部亮成同一个颜色**（不是每灯一色）。

为什么？弹奏和学习共用一套颜色，用户弹着弹着就形成了"红=do"的肌肉记忆，学习模式一看灯色就知道按哪。**这是用户提出并坚持的设计**，比"每键不同色分布在五灯上"更利于记忆。

> ⚠️ 实现注意：WS2812 的颜色顺序是 **GRB**，不是常见的 RGB。红绿会反，必须按 GRB 发送。

## 4. 输入：按键与旋钮

### 按键分工
| 键 | 功能 |
|---|---|
| S1~S7 | 7 个音（受八度档位影响） |
| S8 | 短按=录音，长按=回放 |
| 旋钮（S9） | 旋转/短按/长按 |

> 🔧 **要改的一处**：`board_keys.c` 第 127 行把"旋钮按下"和"S8"用逻辑或绑在一起了（`raw = enc_press || s[7]`），两者都触发"播放"。要让它们各干各的，**必须先把这行拆开**。

### 短按 vs 长按（照搬项目 1 的状态机）

```
按下 → [待定] ──按住超过阈值──→ 触发长按 → [已触发]
                 │                              │
              提前松手                        松手
                 ↓                              ↓
            触发短按                        忽略（不重复触发）
```

**代价要清楚**：短按必须等**松手**才生效——因为按下瞬间系统无法预知你要短按还是长按。项目 1 的原话是"松手时才 `dispatch_click`"。

**阈值建议**：旋钮长按（八度）600ms；S8 长按（回放）500ms。
（项目 1 用 3000ms 是因为它触发的是"配置模式"，要防误触；我们的八度是常用操作，不能那么久。）

## 5. 录制：录的是"乐谱"，不是"录音"

### 关键澄清
硬件虽然**有麦克风**（GPIO 9/10/11），但我们**不用它录音**，而是记录：

```
[ 音名 , 按下时刻毫秒 ]  →  一串数字，就是简谱
```

**为什么不录真实音频**：
1. 键盘没有外放录音的必要——录按键顺序能**精确回放**，且能用于学习模式的"判对"
2. 音频波形占空间大、无法判对错
3. 麦克风留作后期"自定义音色"（录一个真实声音当琴键音）

### 存储三层
| 层 | 介质 | 特点 | 用途 |
|---|---|---|---|
| 1 | RAM（内存） | 快，断电丢失 | 弹奏时实时记录 |
| 2 | Flash（闪存） | 断电不丢，但**擦写有寿命** | 弹完一整首才写一次 |
| 3 | 电脑 | 无限 | 连上自动同步，永久存档 |

> ⚠️ **不要每按一键就写一次 Flash**——擦写寿命约 10 万次，频繁写会磨损。必须"弹完整首才写一次"。

## 6. 状态灯（本次新增）

板子上除了五颗 WS2812，还有一颗**独立的 PWM 状态灯**（GPIO42），beatbox 完全没用。我们用它让设备"会说话"：

| 状态 | 表现 |
|---|---|
| 弹奏待机 | 柔和常亮 |
| 学习模式 | 缓慢呼吸 |
| 录音中 | 快速闪烁 |
| 低电量 | 红色 |

成本极低（几行代码），但解决了"不知道设备在干嘛"的问题。

## 8. 关键取舍记录（为什么不是那样）

| 决策 | 选了 | 否决了 | 原因 |
|---|---|---|---|
| 工程基座 | beatbox | easy-input-maker | beatbox 有发声引擎；maker 要现搬一套发声，工作量大 |
| 发声方式 | 现场合成 | 播放采样文件 | 零存储、音长灵活、换音色只改参数 |
| 录音内容 | 按键顺序 | 音频波形 | 能精确回放、能判对、体积小（且无此需求） |
| 灯的显示 | 五灯统一同色 | 五灯各一色 | 颜色=音的身份证，利于记忆（用户提出） |
| 旋钮方案 | 音量/切模式/八度 | 只管音量；或做成菜单系统 | 功能全且不复杂；菜单系统过度设计 |

## 9. 硬件红线（写代码前必读）

来自 `easyinput-board-cy/references/known-gaps-and-errata.md`，**这些曾被人搞错**：

| ❌ 错误 | ✅ 正确 |
|---|---|
| S1 = GPIO1 | **S1 = GPIO2** |
| S5 = GPIO0 | **S5 = GPIO1**（GPIO0 只用于 BOOT） |
| S6/S7 = GPIO5/6 | **S6/S7 = GPIO6/7** |
| GPIO8 只是灯的开关 | **GPIO8 是灯+麦+喇叭的共享总电源** |
| 发黑帧 = 关电源 | 黑帧只熄灯，**不动 GPIO8** |
| SEN_CHRG 高 = 充满 | 外部供电时，**高=充电中**，低=充满 |
| BOOT 要按住再上电 | **开机状态短按一下**即可进下载模式 |
| 板上有 RESET 键 | **没有**独立 RESET 键 |
| GPIO26~37 可用 | **是内存总线，绝对禁用** |

**GPIO8 上电时序**：拉高 GPIO8 之前，必须先把 `LED_DIN`、`SPK_BCLK/WS/DOUT`、`MIC_BCLK/WS` 输出低电平，否则可能异常。
