# 操作手册

> 给拿到这台电子琴的人。**不用懂技术，照着玩就行。**

## 一、这是什么

一台只有 8 个键的小电子琴。它有**三个本事**：

1. **能弹**——7 个键就是 do re mi fa sol la si
2. **能录**——你弹的曲子它记得住，能原样重放
3. **能教**——灯会亮起颜色告诉你"该按哪个键"，跟着学就会弹歌

## 二、认识你的琴

```
    ┌──────┬──────┬──────┬──────┐        ╭──────╮
    │  do  │  re  │  mi  │  fa  │        │      │
    │ 红   │ 橙   │ 黄   │ 绿   │        │ 旋   │
    │ S1   │ S2   │ S3   │ S4   │        │ 钮   │
    ├──────┼──────┼──────┼──────┤        ╰──────╯
    │ sol  │  la  │  si  │ 录音 │
    │ 青   │ 蓝   │ 紫   │ S8   │
    │ S5   │ S6   │ S7   │      │
    └──────┴──────┴──────┴──────┘

    ●    ●    ●    ●    ●        ← 五颗灯 D1~D5
   D1   D2   D3   D4   D5
```

## 三、七个琴键

| 键 | 唱名 | 颜色 | 键 | 唱名 | 颜色 |
|---|---|---|---|---|---|
| **S1** | do | 🔴 红 | **S5** | sol | 🟦 青 |
| **S2** | re | 🟠 橙 | **S6** | la | 🔵 蓝 |
| **S3** | mi | 🟡 黄 | **S7** | si | 🟣 紫 |
| **S4** | fa | 🟢 绿 | | | |

**按下去会发生两件事**：发出对应的音，同时**五颗灯全部亮成这个键的颜色**。

> 💡 为什么五颗灯亮同一个颜色？因为颜色就是这个音的"身份证"。你弹着弹着就记住"红=do、蓝=la"，后面学歌时一看灯的颜色就知道按哪。

**可以同时按几个键**——两个音会一起响（就像钢琴弹和弦）。

## 四、第八个键 S8：录音与回放

| 操作 | 作用 |
|---|---|
| **短按一下** | 开始录音 / 停止录音 |
| **按住约 半秒** | 回放刚才录的曲子 |

录的时候状态灯会闪，录完再按一下 S8 就停。

## 五、旋钮（右边那个轮子）

| 操作 | 作用 |
|---|---|
| **转动** | 弹奏模式：调音量大小；学习模式：换歌曲 |
| **短按** | 切换「弹奏模式 / 学习模式」（松手时生效） |
| **按住约半秒** | 升降八度（声音整体变高或变低一档） |

**什么是八度？** 把它想成"音高的档位"：

| 档位 | 效果 | do 的音高 |
|---|---|---|
| 低八度 | 低沉，像大提琴 | 131 Hz |
| **正常（默认）** | 标准 | 262 Hz |
| 高八度 | 清亮，像铃铛 | 523 Hz |

7 个键 × 3 个八度 = **能弹出 21 个不同的音**，能弹的曲子一下子多很多。

## 六、灯都在说什么

### 五颗灯（D1~D5）

| 现象 | 含义 |
|---|---|
| 全亮成**某一个颜色** | 你正按着那个颜色的键 |
| 学习模式下亮色 | **提示：请按这个颜色的键** |
| 闪一下 | 按错了，再试一次 |
| 全灭 | 没在按键 |

### 状态灯（琴上另一颗独立的小灯）

| 现象 | 含义 |
|---|---|
| 柔和常亮 | 弹奏模式，待命中 |
| 缓慢呼吸 | 学习模式 |
| 快速闪烁 | **正在录音** |
| 红色 | 电量低了，该充电 |

## 七、两种模式怎么用

### 弹奏模式（开机默认）
随便按 S1~S7 就能弹。想录下来就短按 S8 开始弹，弹完再按 S8 停，长按 S8 回放。

### 学习模式
1. **短按旋钮**切到学习模式（状态灯开始呼吸）
2. **转动旋钮**挑一首歌
3. 灯会亮起一个颜色——**按那个颜色的键**
4. 按对了 → 发出声音，灯跳到下一个音
5. 按错了 → 灯闪一下，等你按对

## 八、来，弹一首《小星星》

```
do do sol sol la la sol     （红红 青青 蓝蓝 青）
fa fa mi mi re re do        （绿绿 黄黄 橙橙 红）
sol sol fa fa mi mi re      （青青 绿绿 黄黄 橙）
sol sol fa fa mi mi re      （青青 绿绿 黄黄 橙）
do do sol sol la la sol     （红红 青青 蓝蓝 青）
fa fa mi mi re re do        （绿绿 黄黄 橙橙 红）
```

照着颜色按就行——这就是"看颜色弹琴"。

## 九、常见问题

**Q：按下去没声音？**
先转旋钮把音量调大；再确认状态灯是不是红色（没电了）。

**Q：灯不亮？**
灯和喇叭共用一路电源，开机后要等一下才准备好。如果一直不亮，检查电量。

**Q：录的曲子关机后还在吗？**
在的，存在芯片里，断电也不会丢。

**Q：为什么短按旋钮要等松手才切换？**
因为系统要知道你到底是"短按"还是"长按"——只能等松手那一刻才能确定。正常按一下（不到半秒）几乎感觉不到延迟。

**Q：能连手机吗？**
当前版本用电脑 USB 连接（网页控制）。手机支持在计划中，会用"网页蓝牙"实现，不用装 App。
