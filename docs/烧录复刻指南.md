# 烧录复刻指南

> 给想把这台电子琴"复制到自己板子上"的人。
> **两条路**：新手直接烧现成固件（第 2 节）；想改代码的人自己编译（第 3 节）。

> [!WARNING]
> **本文对应的是旧版（7 音电子琴 + 旧的 A 族分区表），请勿直接照抄到现在的 6 槽版本。**
> 本文说「应用固件烧到 `0x10000`」—— 那是**旧分区表里的 factory 槽**；而在**现在的 6 槽分区表里，`0x10000` 是 `otadata`（不是应用槽）**。若把当前固件按本文的地址写到 `0x10000`，会**覆盖 otadata**。
> 当前版本的烧录口径：**app 写到 `0x20000`（`ota_0`）、语音 `voice_prompts.vpmt` 单独写到 `rec` 分区 `0x9D8000`** —— 详见 `firmware/build/flash_args` 与 `docs/八音琴-真机验收清单.md`。
> 本文与「固件库」里的老固件 + 它自带的 `partition-table.bin` 是**成套**的，单独混用会出错。

## 1. 开始前：你需要准备什么

### 硬件
- 一块 **EasyInput V2.0** 开发板（PCB 丝印可能是 "AI Keyboard V2.1"，是同一块板）
- 一根 **USB 数据线**（要能传数据的，不是只能充电的）
- 一台 Windows 电脑

### 软件
- **ESP-IDF v5.5.5**（乐鑫官方开发框架）
- **esptool**（烧录工具，装 ESP-IDF 时自带）
- **Python 3**（esptool 依赖）

### 固件文件（三件套）
| 文件 | 烧到哪个地址 | 说明 |
|---|---|---|
| `bootloader.bin` | `0x0` | 启动引导 |
| `partition-table.bin` | `0x8000` | 分区表 |
| 应用固件 `.bin` | `0x10000`（**旧表**） | 电子琴主程序 —— ⚠️ 仅适用于旧的 A 族分区表；**当前 6 槽版请写 `0x20000`** |

> 📦 现成固件放在 `E:\easyIntput\固件库\`，找最新日期的那个。

## 2. 路线 A：直接烧现成固件（推荐新手）

### 步骤 1：让板子进入"下载模式"

> ⚠️ **这不是按住 BOOT 再上电！** 老教程那么写是错的。

正确做法：**板子处于开机状态 → 短按一下 BOOT 键 → 松开**，就进下载模式了。

（BOOT 键在 GPIO0，板子上的小按键。）

### 步骤 2：验身（**必做**，防止烧错板子）

```bash
python -m esptool --chip esp32s3 -p <你的端口> chip_id
```

确认两件事：
- 芯片是 **ESP32-S3**
- MAC 地址**和你预期的是同一块板**（核对后四位即可）

> 🔒 为什么必须验身：电脑上可能插着好几块板子，烧错就麻烦了。这一步不能省。

Windows 端口名形如 `COM5`。不确定是哪个？设备管理器里看，或者拔插对比。

### 步骤 3：烧录

```bash
python -m esptool --chip esp32s3 -p COM5 -b 460800 \
  write_flash \
  0x0      bootloader.bin \
  0x8000   partition-table.bin \
  0x10000  <电子琴固件>.bin
```

看到三行 `Hash of data verified` 就成功了。

> ⚠️ **不要加 `--erase-all`（整片擦除）**，普通烧录就够了，整片擦除风险更高。

### 步骤 4：退出下载模式

**关机 → 再开机**（下载模式只能靠断电退出，软件复位出不来）。

### 步骤 5：验证（逐项打勾）

- [ ] 开机后五颗灯亮一下（自检）
- [ ] 状态灯柔和常亮（待机）
- [ ] 按 S1 → 听到 do，五灯全红
- [ ] 按 S2~S7 → 各听到对应音高，灯色不同
- [ ] 转旋钮 → 音量变大变小
- [ ] 按住旋钮半秒 → 音高整体变高（升八度）
- [ ] 短按旋钮 → 状态灯变呼吸（切到学习模式）

## 3. 路线 B：自己编译（想改代码的人）

### 源码在哪

本项目基于 **`easyinput-beatbox` 二次开发**，代码改动在本工程的：

```
easyinput-piano/firmware/main/
├── audio/audio_click.c/.h      ← 现场合成 7 音（核心）
├── main.c                       ← 按键映射、旋钮控制
├── board/board_keys.c           ← 拆开旋钮按下与 S8
└── music_notes.h                ← 7 频率表 + 7 颜色表（新增）
```

### 编译命令

```bash
cd E:/easyIntput/easyinput-piano/firmware
idf.py set-target esp32s3
idf.py build
```

### ⚠️ 编译的三个大坑（都是踩过的）

**坑 1：`ninja: error: remove(...obj): Access is denied`**
- 原因：后台运行时沙箱拦截，ninja 无法删/写 build 目录
- 解法：**前台运行编译命令**，不要用后台任务

**坑 2：`idf.py flash` 退出码 2，日志写权限不足**
- 解法：改用 **esptool 直接烧录**（见第 2 节步骤 3），不经过 idf.py

**坑 3：端口被占用（`PermissionError`）**
- 原因：网页控制台连着串口没关
- 解法：**先关掉网页**，再烧录

### 电脑上先跑测试（**别跳过**）

```bash
cd easyinput-piano/firmware/host_test
cmake -B build && cmake --build build && ctest
```

测试全绿才烧录。这是本项目铁律：**先测后烧**。

## 4. 常见问题

| 现象 | 原因 | 解法 |
|---|---|---|
| 电脑认不出板子 | 没进下载模式 / 线只能充电 | 开机状态短按 BOOT；换数据线 |
| `chip_id` 读不出 | 端口被占用 | 关闭网页 / 串口监视器 |
| 烧录到一半失败 | 波特率太高或线不稳 | 把 `-b 460800` 改成 `-b 115200` |
| 灯亮但没声音 | 喇叭共用电源没起来 | 断电重启；检查 GPIO8 电源轨 |
| 烧完还是旧固件 | 没退出下载模式 | 关机再开机 |
| 编译报 GPIO 冲突 | 用了保留引脚 | GPIO26~37 是内存总线，**绝对不能用** |

## 5. 安全须知（红线）

1. ❌ **不要整片擦除 flash**（`--erase-all`）——会连校准数据一起清掉
2. ❌ **不要跳过验身**——烧错板子不可逆
3. ❌ **不要用"按住 BOOT 再上电"的老方法**——当前板不支持
4. ✅ 每次烧录前，完整 MAC 只在屏幕上临时显示，**不要写进公开文档**
5. ✅ 烧录后的固件，建议存一份到 `固件库/` 并标注日期和变更内容，方便随时回退

## 附：硬件引脚速查（写代码时用）

| 功能 | 引脚 |
|---|---|
| 按键 S1~S8 | GPIO 2 / 47 / 38 / 41 / 1 / 6 / 7 / 48 |
| 旋钮 A / B / 按下 | GPIO 17 / 16 / 18（按下丝印为 **S9**） |
| 五颗灯（WS2812） | GPIO 12，**颜色顺序 GRB** |
| 状态灯 | GPIO 42（PWM） |
| 喇叭（I2S） | BCLK 14 / WS 13 / DOUT 15 |
| 麦克风（I2S） | BCLK 9 / WS 10 / DIN 11 |
| 外设总电源 | GPIO 8（**高电平有效**，灯+麦克风+喇叭共用） |
| BOOT | GPIO 0（仅下载用） |
| 保留 | GPIO 26~37（内存总线，**禁用**） |
