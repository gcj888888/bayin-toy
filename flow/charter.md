# 项目宪章 (charter)

> 所有 Agent / 协作者开工要读的第一份。本项目的目标、边界与红线都在这里。

- **项目名**：EasyInput 电子琴（easyinput-piano）
- **目标**（做成什么样算成功，一句话）：
  把 EasyInput V2.0 这块 8 键键盘，变成一台**能弹、能录、还能教人弹**的小电子琴——7 个键发出 do~si，五颗灯用颜色告诉你该按哪个键。
- **范围**：
  - **做**：
    - **弹奏模式**：S1~S7 发出 do re mi fa sol la si（芯片现场合成声音），按下时五颗灯统一亮成该键的颜色
    - **控制**：旋钮旋转调音量、短按切换模式、长按升降八度；S8 短按录音、长按回放
    - **录制与回放**：记录"按了哪个音 + 什么时候按的"，存进芯片，可回放，可同步到电脑
    - **学习模式**：内置歌曲，灯亮颜色提示该按哪个键，按对才发声
    - **网页端**：选歌、看进度、调音色参数与音量亮度
    - **状态灯**：模式指示、录音中闪烁、低电量提醒
  - **不做**（明确划界，避免跑偏）：
    - **不做真实音频录制**（麦克风留到后期做"自定义音色"）
    - **不做手机原生 App**（后期如需，用"网页蓝牙"轻量实现）
    - 不做多轨编曲、不做 MIDI 输出、不做和弦自动伴奏——超出当前范围
- **约束**（必须遵守）：
  1. **硬件只信真相源**：引脚、芯片、电源一律以 `easyinput-board-cy/references/board-contract.json` 为准，不凭印象写 GPIO
  2. **遵守硬件勘误清单**：`easyinput-board-cy/references/known-gaps-and-errata.md` 里 11 条"必须拦截的历史错误"，一条都不能犯
  3. **复用优先**：代码基于 `easyinput-beatbox` 二次开发（发声/按键/灯/网页/存储全是现成的），不另起炉灶
  4. **先测后烧**：每一步都先在电脑上跑测试，测试通过、用户确认后，才允许烧录
  5. **烧录安全**：写入前必须重新验身（核对完整 MAC 与芯片型号），并取得用户本轮明确确认句
- **成功标准**（可衡量）：
  | 阶段 | 验收 |
  |---|---|
  | ① 能弹 | 按 S1~S7 各发出对应音高；五灯统一亮该键颜色；旋钮能调音量、长按能换八度 |
  | ② 会记会放 | 弹一段 → S8 长按回放，音高与节奏和刚才一致 |
  | ③ 会教 | 跟着灯能完整弹出一首内置歌曲 |
  | ④ 上网页 | 电脑能选歌、看进度、调音色 |
- **角色**：拍板 = 用户 / 主控 = Claude Code / 真机验收 = 用户
- **红线**：
  - 任何烧毁硬件、整片擦除 flash、绕过验身直接烧录的操作，**一律禁止**
  - 不修改未授权的第三方代码；改造范围严格限定在本文档列出的文件

## 硬件基线（速查，详细真相源见 board-cy）

| 项 | 规格 |
|---|---|
| 主控 | ESP32-S3R8（QFN56） |
| 内存 | 8 MB PSRAM（内置） + 16 MB Flash（外挂 W25Q128） |
| 输入 | 8 个键 S1~S8、旋钮（A/B/按下，丝印 **S9**）、KEY_WAKE |
| 输出 | 5× WS2812 灯（**颜色顺序 GRB**）、状态灯（GPIO42，PWM） |
| 音频 | 扬声器 MAX98357A（I2S）、麦克风（I2S，本项目暂不用） |
| 通信 | 原生 USB（GPIO19/20）+ 蓝牙（板载 PCB 天线） |
| 电源 | GPIO8 = 灯/麦克风/喇叭的**共享总电源**（高电平有效） |
