🎮 游戏

📖 游戏说明

① 开始前选 简单模式（音符慢慢落，约原曲 0.25 倍速）或 专家模式（按原曲速度）。
② 音符会一个接一个从上面落下来，落到虚线处会停下来等你按。
③ 用电脑键盘 1~8（或板子 S1~S8）按对应的音；按对才出下一个，按错只闪红、不前进，再按即可。
④ 音符下落的快慢来自曲子本身两个音之间的间隔：专家模式按原速，简单模式给你四倍反应时间。
⑤ 通关后这首曲子自动存进板子的回放池（最多 5 首，满了覆盖最旧的）；中途退出或失败不会存。

⏹ 退出本局

退出会停动画 / 停背景音，并发 record:0 丢弃这次记谱，不会进回放池，界面回到初始态。想回板子主目录？长按旋钮 ≥5 秒。

🔈 音源与声音

🔊 音源

板子响＝由开发板发声；电脑响＝网页用 Web Audio 合成 8 个音（do~高音哆），没接板子也能听到声音练手。背景音默认关闭，需要时手动打开。

🧩 其它模式

🎼 学习模式（阶段③）

选歌后进入学习模式：D1~D5 五灯亮成“下一个要弹的音”的颜色，你按对才响、按错不前进（颜色不变=提示重来）。 整首弹完灯变柔白。也可以短按旋钮进/出学习模式、演示按钮让板子自动弹一遍。

🎵 库管理

🎵 曲库管理（5 槽 · 同步写 flash）

这里是试听曲库（出厂 3 首 + 网页管理），共 5 槽（0~4）。新增 / 替换会写进键盘 flash（断电不丢）。你自己弹的曲子、以及游戏通关的曲子会自动进「回放」。

🗣️ 开机语音（新增）

开机默认播人声“欢迎来到AI音乐世界”。点“导入我的语音”选一个 ≤10 秒的音频（mp3/wav 都行），会盖过默认、开机优先播导入的；想还原就点“恢复默认语音”。导入中请耐心等待，进度条走完即成功。

📖 说明

🎮 游戏说明

音符方块上显示的是中文唱名：哆/唻/咪/发/嗦/啦/唏/高哆（右下角小字＝键号，1~8 对应 S1~S8）。 底部小狐狸会滑到该音轨下瞄准 —— 按对键射中爆开，按错就射偏、本局结束。
玩法（在「🎮 游戏玩法」里切换）：不限时＝一次只出一个音符，按对才从上方出下一个；踩节奏＝整段按拍连续下落，±0.22 秒内踩中才得分（漏拍也算失败）。
电脑也能玩：按键盘 1~8 就等于按板子 S1~S8；8 = 高音哆。录音/回放为对局自动触发（不再绑按键）。
想让没接板子也能听到声音，到「🔊 音源」把发声改成「电脑响」。 开始前把板子切到「弹奏模式」（状态灯常亮、别是呼吸）：这样按键才出声、也才会被录下来。开局 record:1，通关 record:0 后 400ms 回放（通关曲目由板端记谱进「回放池」）；中途失败丢弃。

打开方式：终端运行 python -m http.server 8765，浏览器访问 http://127.0.0.1:8765/index.html（板子不会播报网址，录屏请看这里）。
